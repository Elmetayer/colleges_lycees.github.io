Comment ce site est construit

Ce site est un projet personnel, conçu par Bruno Lemetayer et développé avec l'aide de Claude, un assistant d'intelligence artificielle de l'entreprise Anthropic.

Qui fait quoi

  • Bruno Lemetayer décide de ce que montre la carte : les indicateurs retenus, la façon de présenter ce qui est incertain, l'ordre des étapes. Il valide chaque modification avant sa mise en ligne.
  • Claude explore les sources de données, propose des façons de faire, et écrit le code qui prépare les données, celui du site, les tests automatiques et une grande partie de cette documentation. Chaque modification est proposée sous forme de demande de fusion, que Bruno Lemetayer accepte ou refuse.

Ce que l'IA ne fait pas

  • Elle n'invente aucune donnée. Les chiffres, les secteurs et les zones viennent de fichiers publics, listés sur la page Sources. Un programme sans IA les recalcule à chaque mise à jour, et son code est public.
  • Aucune IA ne fonctionne sur le site lui-même : pas d'assistant conversationnel, pas de texte généré à la volée, aucune information sur les visiteurs transmise à une IA.
  • Elle ne note pas les établissements. Les indicateurs sont ceux que publie le ministère de l'Éducation nationale, comparés aux médianes de l'académie et de la France.

Comment les erreurs sont limitées

  • Avant chaque mise en ligne, des tests automatiques vérifient les données (nombre d'établissements, indicateurs disponibles, secteurs comparés aux secteurs officiels) et l'affichage sur ordinateur et sur téléphone. Si un test échoue, le site n'est pas mis à jour.
  • La page Suivi des données montre, pour chaque mise à jour, ce qui a été récupéré et ce qui a manqué.
  • Ce qui est reconstitué ou approximatif est signalé comme tel : secteurs des collèges reconstitués, écoles qui accueillent « en principe » les enfants de la commune (règle de la commune).
  • Le code est public sur GitHub : chacun peut vérifier comment les chiffres sont obtenus.

Les limites

Une IA peut se tromper, comme une personne. Malgré ces contrôles, des erreurs restent possibles. Pour une décision importante, une inscription par exemple, la réponse qui fait foi est celle de l'établissement, de la mairie ou de l'académie.

Pour signaler une erreur, ouvrez une demande (« issue ») sur GitHub, en indiquant l'établissement ou l'adresse concernés et ce qui vous semble faux. Un compte GitHub, gratuit, est nécessaire.
